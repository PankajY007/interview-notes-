## 💡 Quick Revision Checklist

- [ ] Can you explain HashMap internal working in 5 minutes?
- [ ] Can you write a Singleton pattern with thread safety?
- [ ] Can you explain Spring Bean lifecycle?
- [ ] Do you know the difference between `@Component` vs `@Service` vs `@Repository`?
- [ ] Can you design a REST API for an e-commerce cart?
- [ ] Can you write a SQL query with JOINs and Window Functions?
- [ ] Can you explain the N+1 problem and how to fix it?
- [ ] Can you explain Circuit Breaker pattern?
- [ ] Can you solve a medium LeetCode problem in 30 minutes?
- [ ] Can you explain `git rebase` vs `git merge`?

---

> **Tip:** Start each study session by reviewing the checklist above. When you can confidently check all boxes, you're interview-ready! 🚀
